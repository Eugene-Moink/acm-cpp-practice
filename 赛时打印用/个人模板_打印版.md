## 快速读入与整体框架

适用场景：所有题目的起手式，输入量大时用快读。
复杂度：单次读入接近 O(1)。
易错点：多组数据要清空全局数组和图；快读不要和 scanf 混用。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll INF = (ll)4e18;
const int MOD = 1000000007;

int readInt() {
    int x = 0, f = 1;
    char c = getchar();
    while (c < '0' || c > '9') {
        if (c == '-') f = -1;
        c = getchar();
    }
    while (c >= '0' && c <= '9') {
        x = x * 10 + (c - '0');
        c = getchar();
    }
    return x * f;
}
```

## 二分查找（整数）

适用场景：有序数组中找第一个大于等于 x 的位置。
复杂度：O(log n)。
易错点：统一写 l <= r 的闭区间；mid 写 l + (r - l) / 2 防溢出。

```cpp
int lower_bound_idx(const vector<int>& a, int x) {
    int l = 0, r = (int)a.size() - 1, ans = -1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] >= x) {
            ans = mid;
            r = mid - 1;
        } else {
            l = mid + 1;
        }
    }
    return ans;
}
```

## 二分答案

适用场景：求最小的可行值，答案具有单调性。
复杂度：O(log(值域) * check 复杂度)。
易错点：check 全用 long long；初始区间要包含答案；while 内真的缩区间。

```cpp
bool check(ll mid) {
    return true;
}

ll binary_answer(ll lo, ll hi) {
    ll l = lo, r = hi, ans = -1;
    while (l <= r) {
        ll mid = l + (r - l) / 2;
        if (check(mid)) {
            ans = mid;
            r = mid - 1;
        } else {
            l = mid + 1;
        }
    }
    return ans;
}
```

## 前缀和与差分

适用场景：多次询问区间和，或多次区间加后统一输出。
复杂度：预处理 O(n)，单次操作 O(1)。
易错点：pre[0] 置 0；差分数组开 n + 2；区间是闭区间 [l, r]。

```cpp
vector<ll> build_pre(const vector<ll>& a) {
    int n = (int)a.size();
    vector<ll> pre(n + 1, 0);
    for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + a[i];
    return pre;
}

ll range_sum(const vector<ll>& pre, int l, int r) {
    return pre[r + 1] - pre[l];
}

void diff_add(vector<ll>& d, int l, int r, ll v) {
    d[l] += v;
    d[r + 1] -= v;
}
```

## 二维前缀和与差分

适用场景：矩阵子矩形求和，或对子矩形统一加值。
复杂度：预处理 O(n * m)，单次操作 O(1)。
易错点：下标一律从 1 开始；子矩阵加要改四个角；求和公式符号别抄错。

```cpp
ll s[1005][1005], d[1005][1005];

void build_2d(int n, int m) {
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            s[i][j] += s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1];
        }
    }
}

ll rect_sum(int x1, int y1, int x2, int y2) {
    return s[x2][y2] - s[x1 - 1][y2] - s[x2][y1 - 1]
           + s[x1 - 1][y1 - 1];
}

void rect_add(int x1, int y1, int x2, int y2, ll v) {
    d[x1][y1] += v;
    d[x1][y2 + 1] -= v;
```

## 尺取法（同向双指针）

适用场景：求和不超过 S 的最长区间，或最短的满足条件的区间。
复杂度：O(n)。
易错点：先加右端点再收缩左端点；收缩用 while 不是 if；和用 long long。

```cpp
int longest_at_most(const vector<int>& a, ll S) {
    int n = (int)a.size(), l = 0, best = 0;
    ll sum = 0;
    for (int r = 0; r < n; r++) {
        sum += a[r];
        while (sum > S) {
            sum -= a[l];
            l++;
        }
        best = max(best, r - l + 1);
    }
    return best;
}
```

## 离散化

适用场景：数值很大但只有相对大小重要，配合树状数组或二分。
复杂度：O(n log n)。
易错点：必须 unique；查询拿到的是下标不是值。

```cpp
vector<int> compress(vector<int> a) {
    vector<int> b = a;
    sort(b.begin(), b.end());
    b.erase(unique(b.begin(), b.end()), b.end());
    for (int& x : a) {
        x = (int)(lower_bound(b.begin(), b.end(), x) - b.begin()) + 1;
    }
    return a;
}
```

## 最大子段和（Kadane）

适用场景：求连续子段的最大和，允许负数。
复杂度：O(n)。
易错点：cur = max(cur + x, x)；全负数时答案是最大的单个元素。

```cpp
ll max_subarray(const vector<ll>& a) {
    ll cur = 0, best = LLONG_MIN;
    for (ll x : a) {
        cur = max(cur + x, x);
        best = max(best, cur);
    }
    return best;
}
```

## 0/1 背包

适用场景：每件物品只能取一次，在容量限制下求最大价值。
复杂度：O(n * V)。
易错点：容量必须倒序循环；求恰好装满时 dp[0] = 0 其余为 -INF。

```cpp
ll knapsack01(int V, const vector<int>& w, const vector<ll>& v) {
    vector<ll> dp(V + 1, 0);
    int n = (int)w.size();
    for (int i = 0; i < n; i++) {
        for (int j = V; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    return dp[V];
}
```

## 完全背包

适用场景：每件物品可以取无限次，在容量限制下求最大价值。
复杂度：O(n * V)。
易错点：容量必须正序循环；只有循环方向不同，别和 0/1 背包写混。

```cpp
ll knapsack_full(int V, const vector<int>& w, const vector<ll>& v) {
    vector<ll> dp(V + 1, 0);
    int n = (int)w.size();
    for (int i = 0; i < n; i++) {
        for (int j = w[i]; j <= V; j++) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    return dp[V];
}
```

## 最长上升子序列（O(n log n)）

适用场景：求最长的严格递增子序列长度。
复杂度：O(n log n)。
易错点：dp 里存的是长度 i + 1 的上升子序列的最小结尾；非严格用 upper_bound。

```cpp
int lis_length(const vector<int>& a) {
    vector<int> dp;
    for (int x : a) {
        auto it = lower_bound(dp.begin(), dp.end(), x);
        if (it == dp.end()) dp.push_back(x);
        else *it = x;
    }
    return (int)dp.size();
}
```

## 最长公共子序列

适用场景：求两个序列的最长公共子序列长度。
复杂度：O(n * m)。
易错点：下标从 1 开始写最省事；只求长度可以滚动数组压掉一维。

```cpp
int lcs_length(const string& a, const string& b) {
    int n = (int)a.size(), m = (int)b.size();
    vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (a[i - 1] == b[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
            else dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    return dp[n][m];
}
```

## 网格路径 DP

适用场景：数路径方案数，或求最小路径和。
复杂度：O(n * m)。
易错点：边界 dp[0][j] 与 dp[i][0] 要单独初始化；障碍点直接跳过。

```cpp
ll grid_count(int n, int m, vector<string>& g) {
    vector<vector<ll>> dp(n, vector<ll>(m, 0));
    dp[0][0] = (g[0][0] == '.' ? 1 : 0);
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (g[i][j] == '#') {
                dp[i][j] = 0;
                continue;
            }
            if (i == 0 && j == 0) continue;
            ll from_up = (i > 0 ? dp[i - 1][j] : 0);
            ll from_left = (j > 0 ? dp[i][j - 1] : 0);
            dp[i][j] = (from_up + from_left) % MOD;
        }
    }
    return dp[n - 1][m - 1];
}

ll grid_min_sum(int n, int m, vector<vector<ll>>& a) {
    vector<vector<ll>> dp(n, vector<ll>(m, INF));
    dp[0][0] = a[0][0];
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (i + 1 < n) {
                dp[i + 1][j] = min(dp[i + 1][j], dp[i][j] + a[i + 1][j]);
            }
            if (j + 1 < m) {
                dp[i][j + 1] = min(dp[i][j + 1], dp[i][j] + a[i][j + 1]);
            }
        }
    }
    return dp[n - 1][m - 1];
}
```

## 数位 DP（计数型）

适用场景：统计区间内满足某种数位条件的数字个数。
复杂度：O(位数 * 状态数 * 10)。
易错点：limit 表示是否贴着上界；lead 表示是否还在前导零；结果用前缀相减。

```cpp
int digit[20];
ll memo[20][12][2][2];
bool vis[20][12][2][2];

ll dfs(int pos, int pre, bool limit, bool lead) {
    if (pos < 0) return 1;
    if (vis[pos][pre][limit][lead]) return memo[pos][pre][limit][lead];
    vis[pos][pre][limit][lead] = true;
    int up = limit ? digit[pos] : 9;
    ll res = 0;
    for (int d = 0; d <= up; d++) {
        if (!lead && d == pre) continue;
        bool nlimit = limit && (d == up);
        bool nlead = lead && (d == 0);
        res += dfs(pos - 1, nlead ? 0 : d, nlimit, nlead);
    }
    return memo[pos][pre][limit][lead] = res;
}

ll count_upto(ll n) {
    if (n <= 0) return n + 1;
    int len = 0;
    while (n) {
        digit[len++] = (int)(n % 10);
        n /= 10;
    }
    memset(vis, 0, sizeof(vis));
    memset(memo, 0, sizeof(memo));
    return dfs(len - 1, 0, true, true);
}
```

## 树状数组（单点加 + 区间查）

适用场景：单点修改、前缀和查询，需要在线处理。
复杂度：单次操作 O(log n)。
易错点：下标从 1 开始；lowbit 是 x & -x；区间和是 sum(r) - sum(l - 1)。

```cpp
struct BIT {
    int n;
    vector<ll> t;
    BIT(int n) : n(n), t(n + 1, 0) {}
    void add(int i, ll v) {
        for (; i <= n; i += i & -i) t[i] += v;
    }
    ll sum(int i) {
        ll s = 0;
        for (; i > 0; i -= i & -i) s += t[i];
        return s;
    }
    ll range_sum(int l, int r) {
        if (l > r) return 0;
        return sum(r) - sum(l - 1);
    }
};
```

## 树状数组（区间加 + 单点查）

适用场景：多次区间加，最后询问单点的值。
复杂度：单次操作 O(log n)。
易错点：本质是对差分数组建 BIT；区间加是 l 处加 v、r + 1 处减 v。

```cpp
struct BITDiff {
    int n;
    vector<ll> t;
    BITDiff(int n) : n(n), t(n + 2, 0) {}
    void add(int i, ll v) {
        for (; i <= n; i += i & -i) t[i] += v;
    }
    void range_add(int l, int r, ll v) {
        add(l, v);
        add(r + 1, -v);
    }
    ll point_query(int i) {
        ll s = 0;
        for (int x = i; x > 0; x -= x & -x) s += t[x];
        return s;
    }
};
```

## 并查集

适用场景：合并集合、判断两个元素是否在同一集合。
复杂度：近似 O(1)（路径压缩 + 按大小合并）。
易错点：pre 和 sz 要初始化；合并前必须 find；多组数据重新初始化。

```cpp
struct DSU {
    vector<int> pre, sz;
    DSU(int n) : pre(n + 1), sz(n + 1, 1) {
        for (int i = 1; i <= n; i++) pre[i] = i;
    }
    int find(int x) {
        while (pre[x] != x) {
            pre[x] = pre[pre[x]];
            x = pre[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b) return false;
        if (sz[a] < sz[b]) swap(a, b);
        pre[b] = a;
        sz[a] += sz[b];
        return true;
    }
};
```

## 网格连通块 DFS

适用场景：数网格里连通块的个数，或求某块的大小。
复杂度：O(n * m)。
易错点：先判边界再访问；多组数据清空 vis；递归太深就改 BFS。

```cpp
int n, m;
vector<string> g;
vector<vector<int>> vis;

int dfs(int x, int y) {
    if (x < 0 || x >= n || y < 0 || y >= m) return 0;
    if (g[x][y] == '#' || vis[x][y]) return 0;
    vis[x][y] = 1;
    int cnt = 1;
    cnt += dfs(x + 1, y);
    cnt += dfs(x - 1, y);
    cnt += dfs(x, y + 1);
    cnt += dfs(x, y - 1);
    return cnt;
}

int count_blocks() {
    vis.assign(n, vector<int>(m, 0));
    int blocks = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (g[i][j] == '.' && !vis[i][j]) {
                dfs(i, j);
                blocks++;
            }
        }
    }
    return blocks;
}
```

## 网格 BFS

适用场景：二维网格求起点到各点的最短步数。
复杂度：O(n * m)。
易错点：vis 在入队时打；多组数据清空 dist 和队列；方向数组别写错。

```cpp
const int dx4[4] = {1, -1, 0, 0};
const int dy4[4] = {0, 0, 1, -1};

void bfs(int sx, int sy) {
    dist.assign(n, vector<int>(m, -1));
    queue<pair<int, int>> q;
    dist[sx][sy] = 0;
    q.push({sx, sy});
    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();
        for (int d = 0; d < 4; d++) {
            int nx = x + dx4[d], ny = y + dy4[d];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (g[nx][ny] == '#' || dist[nx][ny] != -1) continue;
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
}
```

## 多源 BFS

适用场景：多个起点同时扩散，求每个点到最近起点的距离。
复杂度：O(n * m)。
易错点：所有起点要先全部入队；dist 初始 -1，起点为 0。

```cpp
void multi_bfs(const vector<pair<int, int>>& src) {
    dist.assign(n, vector<int>(m, -1));
    queue<pair<int, int>> q;
    for (auto [x, y] : src) {
        if (dist[x][y] != -1) continue;
        dist[x][y] = 0;
        q.push({x, y});
    }
    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();
        for (int d = 0; d < 4; d++) {
            int nx = x + dx4[d], ny = y + dy4[d];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (g[nx][ny] == '#' || dist[nx][ny] != -1) continue;
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
}
```

## Dijkstra（堆优化）

适用场景：非负权图的单源最短路。
复杂度：O((n + m) log n)。
易错点：dist 用 long long；弹出时 d != dist[u] 直接跳过；有负权要换 SPFA。

```cpp
vector<ll> dijkstra(int s, vector<vector<pair<int, int>>>& g) {
    int n = (int)g.size() - 1;
    vector<ll> dist(n + 1, INF);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>,
                   greater<pair<ll, int>>> pq;
    dist[s] = 0;
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();
        if (d != dist[u]) continue;
        for (auto [v, w] : g[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}
```

## SPFA（判负环）

适用场景：有负权边的最短路，或判断有没有负环。
复杂度：平均 O(k * m)，最坏 O(n * m)。
易错点：cnt[v] 是入队层数，达到 n 说明有负环；非负权图别用它。

```cpp
bool spfa(int s, int n, vector<vector<pair<int, int>>>& g,
          vector<ll>& dist) {
    dist.assign(n + 1, INF);
    vector<int> cnt(n + 1, 0);
    vector<bool> inq(n + 1, false);
    queue<int> q;
    dist[s] = 0;
    q.push(s);
    inq[s] = true;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        inq[u] = false;
        for (auto [v, w] : g[u]) {
            if (dist[u] + w >= dist[v]) continue;
            dist[v] = dist[u] + w;
            cnt[v] = cnt[u] + 1;
            if (cnt[v] >= n) return true;
            if (!inq[v]) {
                inq[v] = true;
                q.push(v);
            }
        }
    }
    return false;
}
```

## Floyd

适用场景：点数很少（n 不超过 500）时求全源最短路。
复杂度：O(n^3)。
易错点：k 必须在最外层；dist[i][i] = 0；INF 相加前先判。

```cpp
void floyd(vector<vector<ll>>& d, int n) {
    for (int k = 1; k <= n; k++) {
        for (int i = 1; i <= n; i++) {
            if (d[i][k] == INF) continue;
            for (int j = 1; j <= n; j++) {
                if (d[k][j] == INF) continue;
                d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
            }
        }
    }
}
```

## Kruskal（最小生成树）

适用场景：稀疏图求最小生成树。
复杂度：O(m log m)。
易错点：先按边权排序；用并查集判环；边数不足 n - 1 说明不连通。

```cpp
struct Edge {
    int u, v, w;
    bool operator<(const Edge& o) const {
        return w < o.w;
    }
};

ll kruskal(int n, vector<Edge>& edges) {
    sort(edges.begin(), edges.end());
    DSU dsu(n);
    ll total = 0;
    int used = 0;
    for (const Edge& e : edges) {
        if (!dsu.unite(e.u, e.v)) continue;
        total += e.w;
        used++;
        if (used == n - 1) break;
    }
    return used == n - 1 ? total : -1;
}
```

## 拓扑排序（Kahn）

适用场景：DAG 求可行顺序，或判断有向图有没有环。
复杂度：O(n + m)。
易错点：入度 0 的点全部先入队；输出数量少于 n 说明有环。

```cpp
vector<int> topo_sort(int n, vector<vector<int>>& g,
                      vector<int>& indeg) {
    queue<int> q;
    for (int i = 1; i <= n; i++) {
        if (indeg[i] == 0) q.push(i);
    }
    vector<int> order;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        order.push_back(u);
        for (int v : g[u]) {
            if (--indeg[v] == 0) q.push(v);
        }
    }
    return order;
}
```

## 二分图染色判定

适用场景：判断无向图能否二染色，或判断有没有奇环。
复杂度：O(n + m)。
易错点：图可能不连通，要对每个点都试一次；冲突就说明不是二分图。

```cpp
bool is_bipartite(int n, vector<vector<int>>& g) {
    vector<int> color(n + 1, -1);
    for (int s = 1; s <= n; s++) {
        if (color[s] != -1) continue;
        queue<int> q;
        color[s] = 0;
        q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : g[u]) {
                if (color[v] == -1) {
                    color[v] = color[u] ^ 1;
                    q.push(v);
                } else if (color[v] == color[u]) {
                    return false;
                }
            }
        }
    }
    return true;
}
```

## 单调队列（滑动窗口最值）

适用场景：定长窗口内的最大值或最小值。
复杂度：O(n)。
易错点：队头过期要弹出；队尾比较符号决定维护的是最大还是最小。

```cpp
vector<int> window_max(const vector<int>& a, int k) {
    deque<int> dq;
    vector<int> res;
    for (int i = 0; i < (int)a.size(); i++) {
        while (!dq.empty() && dq.front() <= i - k) dq.pop_front();
        while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();
        dq.push_back(i);
        if (i >= k - 1) res.push_back(a[dq.front()]);
    }
    return res;
}
```

## KMP

适用场景：在文本串里找模式串出现的所有位置。
复杂度：O(n + m)。
易错点：nxt 数组开长度加 5；用 1 基下标写最省事。

```cpp
vector<int> build_nxt(const string& p) {
    int m = (int)p.size();
    vector<int> nxt(m + 1, 0);
    for (int i = 2, j = 0; i <= m; i++) {
        while (j && p[i - 1] != p[j]) j = nxt[j];
        if (p[i - 1] == p[j]) j++;
        nxt[i] = j;
    }
    return nxt;
}

vector<int> kmp(const string& s, const string& p) {
    vector<int> nxt = build_nxt(p), res;
    int n = (int)s.size(), m = (int)p.size();
    for (int i = 1, j = 0; i <= n; i++) {
        while (j && s[i - 1] != p[j]) j = nxt[j];
        if (s[i - 1] == p[j]) j++;
        if (j == m) {
            res.push_back(i - m);
            j = nxt[j];
        }
    }
    return res;
}
```

## 字符串哈希（无符号 64 位）

适用场景：O(1) 判断两个子串是否相同。
复杂度：预处理 O(n)，单次查询 O(1)。
易错点：用 unsigned long long 自然溢出；base 取 131 或 13331。

```cpp
using ull = unsigned long long;
const ull BASE = 131;

vector<ull> pw, hs;

void build_hash(const string& s) {
    int n = (int)s.size();
    pw.assign(n + 1, 1);
    hs.assign(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        pw[i] = pw[i - 1] * BASE;
        hs[i] = hs[i - 1] * BASE + (ull)s[i - 1];
    }
}

ull get_hash(int l, int r) {
    return hs[r] - hs[l - 1] * pw[r - l + 1];
}
```

## 快速幂

适用场景：求 a 的 b 次方对 mod 取模。
复杂度：O(log b)。
易错点：底数先取模；b 用 long long；mod 为 1 时结果是 0。

```cpp
ll qpow(ll a, ll b, ll mod) {
    ll res = 1 % mod;
    a %= mod;
    while (b) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}
```

## 数论小工具

适用场景：最大公约数、线性筛素数、试除法分解质因数。
复杂度：gcd 为 O(log n)，筛为 O(n)，分解为 O(sqrt(n))。
易错点：lcm 先除后乘；试除循环写 i <= n / i。

```cpp
ll gcd_ll(ll a, ll b) {
    while (b) {
        ll t = a % b;
        a = b;
        b = t;
    }
    return a;
}

ll lcm_ll(ll a, ll b) {
    return a / gcd_ll(a, b) * b;
}

vector<int> sieve(int n) {
    vector<bool> is_comp(n + 1, false);
    vector<int> primes;
    for (int i = 2; i <= n; i++) {
        if (!is_comp[i]) primes.push_back(i);
        for (int p : primes) {
            if ((ll)i * p > n) break;
            is_comp[i * p] = true;
            if (i % p == 0) break;
        }
    }
    return primes;
}

vector<pair<ll, int>> factorize(ll n) {
    vector<pair<ll, int>> res;
    for (ll i = 2; i <= n / i; i++) {
        if (n % i) continue;
        int cnt = 0;
        while (n % i == 0) {
            n /= i;
            cnt++;
        }
        res.push_back({i, cnt});
    }
    if (n > 1) res.push_back({n, 1});
    return res;
}
```

## 扩展欧几里得与逆元

适用场景：解 ax + by = gcd(a, b)，或求模意义下的乘法逆元。
复杂度：O(log min(a, b))。
易错点：x 可能为负，先取模再加模；a 与 mod 不互质时没有逆元。

```cpp
ll exgcd(ll a, ll b, ll& x, ll& y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    ll g = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return g;
}

ll mod_inverse(ll a, ll mod) {
    ll x, y;
    ll g = exgcd(a, mod, x, y);
    if (g != 1) return -1;
    return (x % mod + mod) % mod;
}
```

## 中国剩余定理（两两合并）

适用场景：解一组同余方程 x ≡ r[i] (mod m[i])。
复杂度：O(n log M)。
易错点：模数可以不互质，用扩展欧几里得合并；中间乘法用 __int128 防溢出。

```cpp
bool crt(const vector<ll>& r, const vector<ll>& m, ll& res,
         ll& lcm_out) {
    ll x = r[0], mod = m[0];
    for (size_t i = 1; i < r.size(); i++) {
        ll a = mod, b = m[i], c = (r[i] - x % b + b) % b;
        ll u, v;
        ll g = exgcd(a, b, u, v);
        if (c % g != 0) return false;
        ll step = b / g;
        ll k = (ll)((__int128)u * (c / g) % step);
        x += (__int128)k * mod;
        mod = (__int128)mod / g * b;
        x = (x % mod + mod) % mod;
    }
    res = x;
    lcm_out = mod;
    return true;
}
```

## 组合数预处理

适用场景：多次求 C(n, m) 对素数取模。
复杂度：预处理 O(n)，单次查询 O(1)。
易错点：fac 和 inv_fac 都开 n + 1；m 超过 n 返回 0。

```cpp
vector<ll> fac, inv_fac;

void init_comb(int n, ll mod) {
    fac.assign(n + 1, 1);
    inv_fac.assign(n + 1, 1);
    for (int i = 1; i <= n; i++) fac[i] = fac[i - 1] * i % mod;
    inv_fac[n] = qpow(fac[n], mod - 2, mod);
    for (int i = n; i >= 1; i--) {
        inv_fac[i - 1] = inv_fac[i] * i % mod;
    }
}

ll comb(int n, int m, ll mod) {
    if (m < 0 || m > n) return 0;
    return fac[n] * inv_fac[m] % mod * inv_fac[n - m] % mod;
}
```

## 几何基础（叉积与多边形面积）

适用场景：判断点与直线位置关系，求简单多边形面积。
复杂度：面积 O(n)。
易错点：叉积为 0 表示共线；面积取绝对值再除以 2。

```cpp
struct Point {
    ll x, y;
};

ll cross(const Point& o, const Point& a, const Point& b) {
    return (a.x - o.x) * (b.y - o.y) - (a.y - o.y) * (b.x - o.x);
}

double polygon_area(const vector<Point>& p) {
    int n = (int)p.size();
    ll s = 0;
    for (int i = 0; i < n; i++) {
        int j = (i + 1) % n;
        s += p[i].x * p[j].y - p[j].x * p[i].y;
    }
    return fabs((double)s) / 2.0;
}
```

## 博弈论 SG 函数

适用场景：公平组合游戏判断先手胜负。
复杂度：O(状态数 * 转移数)。
易错点：多个独立游戏用异或合并；SG 为 0 时先手必败。

```cpp
vector<int> sg;

int get_sg(int x, const vector<int>& moves) {
    if (sg[x] != -1) return sg[x];
    set<int> s;
    for (int m : moves) {
        if (x >= m) s.insert(get_sg(x - m, moves));
    }
    int g = 0;
    while (s.count(g)) g++;
    return sg[x] = g;
}
```
