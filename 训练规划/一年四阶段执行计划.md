# 第四阶段：突破期（第 10–12 月）

### 目标

形成区域赛实战能力，做到 **稳铜，具备冲银机会**。

### 主要做什么

**1. 主打区域赛 VP（60%）**

- ICPC 区域赛往年题、CCPC 区域赛往年题、邀请赛题、网络赛题。
- 频率：**每周 1–2 场 5 小时全真模拟**，全程按正式赛规则（含打印机式读题、禁止查资料）。
- 每场必产出三样东西：**过题清单 + 罚时表 + 选题决策点评**。

**2. 固定队伍配合（明确到人）**


| 角色   | 职责                              | 对应你的能力位           |
| -------- | ----------------------------------- | -------------------------- |
| 开题手 | 前 30 分钟扫题、标难度、分配题目  | 手速快、读题准           |
| 签到手 | 负责最简单 1–2 题，20 分钟内拿下 | 模拟/贪心/前缀和         |
| 中档手 | 负责争铜题（数据结构 + DP 方向）  | 你的主线，需要能独立推进 |
| 查错手 | 提交前通读代码、构造反例、写对拍  | 细心，会写暴力           |

**三人成队时，每人至少兼任两个角色**；每场 VP 后交换一次角色，避免只练一个位置。

**3. 训练开题策略**

- **前 30 分钟扫题**：读完全部题面（至少读完前 8 题），标出"必过 / 可做 / 放弃"。
- 优先拿签到，保证有分在手；再按"可做题里最熟的"顺序推进。
- 明确判断哪些题该跳：**超过 45 分钟无实质推进就跳**，跳之前把思路写下来留给队友。
- **争铜题不能拖太久**：一场 5 小时里，留给中档题的时间预算是 2.5 小时，超了就换题。

**4. 补短板，不再乱学新东西**

- 哪个模块在 VP 中炸了，就补哪个（例如"线段树边界总是写错" → 当周专做 5 道线段树题）。
- 哪种错误重复出现，就专项纠正（例如"多测忘清空" → 一周内所有题强制写 `clear()`）。
- **不再系统学黑名单算法**（见下）。

**5. 冲银题训练（15%）**

- 每场 VP 选 1 道中档题重点突破，重点练 **1600–1900** 区间。
- 不要求每次过，但要能推进思路并写出部分分/暴力。
- 冲银题的常见方向：线段树综合应用、DP 优化、图论综合建模、组合计数 + 容斥、二分答案套数据结构。
- 每突破一道，把思路整理成一段"关键词 → 状态/模型 → 关键结论"存进模板库的注释里。

| 第 10 月 | 固定分工 + 每周 2 场 VP；查漏被 VP 打出来的模块 | CF ≥ 1550；多数 VP 达铜牌线             |
| 第 11 月 | 开题策略专项（扫题/跳题/罚时）；冲银题 4 道     | 队伍 VP 稳定 4 题；低级错误 ≤ 1 次/场   |

# 跨阶段系统（三个阶段都要用）

## A. 算法黑名单与解禁时间


| 算法                       | 解禁时间                     | 理由                       |
| ---------------------------- | ------------------------------ | ---------------------------- |
| Tarjan（割点/桥/SCC）      | 第三阶段                     | 铜牌偶尔出现，但不急       |
| 网络流 Dinic               | 第三阶段（入门即可）         | 区域赛中档偶尔出现         |
| 树链剖分                   | 不学（除非第四阶段明确需要） | 铜牌几乎不用，学习成本极高 |
| 莫队                       | 不学                         | 同上                       |
| 后缀数组 / SAM             | 不学                         | 铜牌 0 收益                |
| FFT / NTT                  | 不学                         | 铜牌 0 收益                |
| 可持久化数据结构、LCT、CDQ | 不学                         | 铜牌 0 收益                |

**判断标准**：一个算法如果在近 3 年区域赛铜牌题里出现次数 ≤ 1，就不值得花超过 3 天。

## B. 四类算法题的固定解题动作


| 题型        | 固定动作                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------- |
| 贪心 / 构造 | 先写暴力跑小样例 → 观察规律 → 猜结论 → 用交换论证或反例验证 → 再写正解                      |
| 二分答案    | 先确认答案单调 → 写`check()` → 用小数据对拍暴力 → 再写外层二分                               |
| DP          | 纸上写清"状态定义 / 转移 / 边界 / 答案位置"四行，再敲代码                                       |
| 数据结构    | 先写暴力版本 → 确认操作类型（点改/区间改、查什么）→ 选 BIT 还是线段树 → 写完先过样例再造数据 |

## C. 四类失误的专项治理


| 失误类型 | 典型表现                         | 治理方式                              |
| ---------- | ---------------------------------- | --------------------------------------- |
| 读题失误 | 漏条件、看错"至少/至多"          | 读题时把关键条件抄到纸上              |
| 边界失误 | `n = 1`、空集、全相等            | 每题强制造一组边界数据                |
| 数值失误 | 溢出、取模、`INF` 不够大         | 提交前 15 秒自查清单                  |
| 结构失误 | 多测不清空、数组开小、图边表开错 | 模板里直接写死`clear()`，不留给自己记 |
