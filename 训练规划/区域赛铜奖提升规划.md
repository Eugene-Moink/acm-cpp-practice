 

# 区域赛铜奖 · 提升规划（2026.09 起）

> 依据：`00_模版/` 现有模板清单、`old/README.md` 刷题统计、2026.08 / 2026.09 目录实际产出，
> 以及 Codeforces（`X_moink`）与 AtCoder（`Morgann`）当前记录。

## 0. 一句话结论

**你现在离铜牌的距离不是"算法不够多"，而是"能稳定 AC 的题型太窄 + 缺少团队赛最吃分的 DP/数据结构"**。
把 CF 从 1260 推到 **1550±50**、AtCoder 从 661 推到 **900+**，并且把
**二分答案、前缀和/差分、贪心、单调栈、背包/线性 DP、树状数组/线段树、最短路、树形 DP** 这 8 块练到"闭卷能写、20 分钟内写完"，
铜牌就是大概率事件；再往前一步（区间 DP、状压 DP、Tarjan、组合数学、计算几何）才是冲银的增量。

## 2. 铜牌需要的能力画像

区域赛（ICPC/CCPC）单场 5 小时 11–13 题，铜牌线通常是**前 30%–50%**的队伍（各赛站不同，
名额按参赛队数分配，金银铜大致 1:2:3）。落到解题上：


| 目标                 | 需要做出    | 对应难度                     | 对应题型                                                                    |
| ---------------------- | ------------- | ------------------------------ | ----------------------------------------------------------------------------- |
| **铜牌（现实目标）** | **3–4 题** | CF Div2 C / ABC D-E / 洛谷绿 | 签到 + 贪心&构造 + 二分答案 + 前缀和/差分 + 简单 DP + 最短路/BFS + 简单数论 |
| 铜牌靠前 / 银牌      | 5–6 题     | CF Div2 D / ABC F / 洛谷蓝   | 线段树/树状数组 + 树形 DP + 区间 DP + 组合数学 + 二分答案套数据结构         |
| 银牌稳               | 7–8 题     | CF 1800–2000                | 状压 DP + Tarjan + 网络流入门 + 计算几何 + 字符串（哈希/Z/KMP）             |

**结论：铜牌 = 把"中档套路题"做到闭卷 20 分钟一首，并且团队三人能覆盖不同方向。**
你不需要会网络流、不用会后缀数组、不需要多项式。你需要的是**基础题零失误 + 中档题至少两个人能打**。

## 3. 能力缺口清单（按优先级）

### P0 — 不补就没铜牌（1 个月内必须全部闭卷）


| 方向        | 具体内容                                                                                         | 你现在                |
| ------------- | -------------------------------------------------------------------------------------------------- | ----------------------- |
| 二分        | 整数二分三种模板（找第一个 true / 最后 true / 浮点）、**二分答案**建模（最大值最小、最小值最大） | 有想法，未系统化      |
| 前缀和/差分 | 一维/二维前缀和、一维/二维差分、离散化后差分                                                     | 模板有 ✅             |
| 贪心 & 构造 | 排序贪心、交换论证、字典序构造、构造小规模样例找规律                                             | 弱（牛客题偏签到）    |
| 基础数论    | gcd/lcm、快速幂、欧拉筛、逆元、**同余与取模运算**、简单组合数预处理                              | 模板有 ✅ 但用得少    |
| 枚举技巧    | 双指针、三分、折半枚举、**按位枚举**、子集枚举                                                   | 弱                    |
| DP 入门     | 线性 DP、**背包五兄弟**（01/完全/多重/分组/依赖）、LIS/LCS、路径计数                             | **空白**              |
| 图论基本功  | 建图、DFS/BFS、连通块、拓扑排序、Dijkstra、Floyd、MST                                            | 模板有 ✅，拓扑排序缺 |
| 树基础      | 树的遍历、子树大小、**树形 DP**（选或不选）、树的直径                                            | 只有 LCA 模板         |

### P1 — 决定你是"压线铜"还是"稳铜"（2–3 个月）


| 方向              | 具体内容                                                                                |
| ------------------- | ----------------------------------------------------------------------------------------- |
| 树状数组          | 单点改区间查、区间改单点查、**区间改区间查**、二维、树状数组上二分                      |
| 线段树            | 单点改区间查、**区间加/区间乘 + 区间求和（懒标记）**、区间最值、动态开点（了解）        |
| ST 表 / 稀疏表    | 静态 RMQ，O(1) 查询                                                                     |
| 单调栈 / 单调队列 | 下一个更大元素、滑动窗口最值、直方图最大矩形                                            |
| 堆                | 优先队列应用、对顶堆、贪心+堆、堆优化 Dijkstra                                          |
| DP 进阶           | 区间 DP、树形 DP（换根）、**状压 DP**、数位 DP、概率期望 DP、DP 优化（前缀和/单调队列） |
| 字符串            | 哈希（已有）、KMP（已有）、Z 函数（已有）、Trie、**字符串哈希判重/最长公共子串**        |
| 数学进阶          | 中国剩余定理、扩展欧拉、矩阵快速幂（已有）、组合计数+容斥、博弈论 SG（已有）            |

### P2 — 冲银才需要（区域赛前 3 个月有余力再说）

Tarjan（割点/桥/SCC/2-SAT）、网络流（最大流 Dinic）、计算几何（向量、叉积、凸包、多边形面积、
圆交）、莫队、可持久化线段树、树链剖分、CDQ 分治、AC 自动机。

### 明确"不要碰"的清单（时间不够时）

后缀自动机、多项式（NTT/FFT）、动态树 LCT、生成函数、计算几何高阶（半平面交/最小圆覆盖）。
**这些对铜牌 0 收益。**

| 周六 | 专题题单 3 题 + 本周错题重做（第二阶段起：每两周 1 场 5 小时团队 VP） | 5 h         |
| 周日 | 模板默写（3 个）+ 填写 §7 度量表                                     | 2 h         |

### 第三、四阶段（第 7–12 月）：VP 驱动


| 时段 | 内容                                                 | 时长 |
| ------ | ------------------------------------------------------ | ------ |
| 周一 | P1 新模块学习（第三阶段）/ VP 补题（第四阶段）       | 3 h  |
| 周二 | P0 巩固题 4 题（1200–1500 手感保持）                | 3 h  |
| 周三 | CF rated 或 Div2 VP + 补题                           | 3 h  |
| 周四 | 冲银题 1 道（1600–1900，允许超时但要写出思路）      | 3 h  |
| 周五 | **5 小时团队 VP**（ICPC 赛制，含读题分工与罚时记录） | 5 h  |
| 周六 | VP 补题 + 每题复盘（谁写、卡在哪、该不该跳）         | 3 h  |
| 周日 | 模板默写（3 个）+ 查漏补缺 + 填写 §7 度量表         | 2 h  |

**总量**：约 22–25 小时/周，15–20 题/周。
你现在是 30 天 60 题（≈14 题/周），所以**题量只微增，但难度必须整体上移一档**（从 div2A/B → div2C/D，从 ABC C → ABC D/E，从洛谷橙 → 洛谷绿/蓝）。

### 赛场纪律（铜牌队最容易丢分的地方）

1. **前 40 分钟必须拿下 2 题**：先扫全卷，把最容易的两题分给手最快的两个人。
2. **单题卡住 30 分钟立刻换题或求助队友**，不要一个人硬磕到比赛结束。
3. **不开赛就冲难题**：5 小时里"3 题 + 零罚时"永远好过"2 题 + 12 次罚时"。
4. **不本地测样例不提交**：区域赛罚时 20 分钟/次，白给。
5. **读完题先写暴力 + 对拍**（尤其在构造题/DP 题上），再写正解。
6. 分工建议：手速型（签到+模拟+贪心）、思维型（构造+DP）、工具型（数据结构+图论+数学）。

### 附：为什么是"这个顺序"

区域赛的题目难度分布是"前 3 题接近签到、中间 3 题是分水岭、后 5 题是银金"。
铜牌线卡在"中档题"上，而中档题最高频的考点按出现频率排序大致是：

**贪心/构造 → 二分 → DP（背包/线性/区间/树形） → 数据结构（树状数组/线段树/单调栈） → 图论（BFS/最短路/拓扑） → 数论组合**

这个排序和本规划的四阶段完全一致。你现在最该做的不是再刷 200 道橙题，
而是**把上面这条主线上的每一环，练到"比赛时能不看模板直接写、并且一次写对"**。
