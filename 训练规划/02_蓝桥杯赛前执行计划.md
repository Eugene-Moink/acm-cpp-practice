**总量**：A1–A6 = 48 道，B1–B4 = 32 道，合计 **80 道**（每周 8 道）。
`06` 文末另有 **40 道备用替换池**（原 120 道里没排进来的），某周太卡或太易时换同主题的进来，不改 `03`。

**阶段目的（为什么是这个顺序）**

- A 段（省赛）：蓝桥杯省赛 B 组的分主要来自**填空 + 中低档编程**，先把「写得快、写得对」打出来，
  再补 DP 和图论；省赛出现的大多是实现类、前缀/二分、简单 DP、搜索。
- B 段（国赛）：国赛才明显上难度——数据结构、区间/树形 DP、组合数学、贡献法。
  **省赛没拿到省一，B 段不必执行**（见 §七）。

## 二、每周固定动作（不计入 8 道题量）

- **填空专项 3 道/周**：蓝桥杯历年真题的填空题（真题来源待补充：官网/洛谷「蓝桥杯」题单）。
  做法固定：**先写一个暴力程序把答案算出来 → 再手算核对 → 两个结果一致才记答案**（填空题没有部分分）。
- **1 场训练赛**：CF Div3/Div2 VP 或 ABC 任选，只当手感训练，**不看 rating 掉分**。
- **错题重写**：本周 WA/TLE 的题，关掉题解独立重写一遍（不是重看）。
- **模板默写 2 个/周**：蓝桥杯必背清单见 [`05_模板库审计_2026-10-18.md`](05_模板库审计_2026-10-18.md) §八。
- **周日**：填 [`04_度量表.md`](04_度量表.md) 本周行 → `git add . && git commit -m "add new note" && git push`。

> 只做 12 h 的周：砍「训练赛」和 1 道题，**填空专项与模板默写不能砍**——这两项是蓝桥杯的直接分数。

## 四、模板纪律（蓝桥杯口径）

- 蓝桥杯考的是**能不能在赛场上默出来**，不是「见过」。所以每个模板的标准是：
  **关掉所有文件，10 分钟内从空白写出来并通过编译 + 自己造的 3 组数据。**
- 必背 20 个清单见 [`05_模板库审计_2026-10-18.md`](05_模板库审计_2026-10-18.md) §八（前缀和差分、二分、离散化、并查集、
  Dijkstra、Kruskal、拓扑、LIS/LCS、01背包/完全背包、区间DP、树形DP、快速幂、gcd、组合数、KMP、哈希、树状数组、ST表、线段树）。
- 模板库现状 `00_模版/` **76 个 .cpp**，索引 `00_模版/README.md`；缺的大件（线段树、ST 表、树形 DP、Trie、Tarjan 等）
  按 `00_模版/README.md` 待补清单排，**先学模板、再拿题库题验证**。
- 写完一个模板：`g++ -std=c++17 -fsyntax-only` 过语法 → `00_模版/README.md` 加行 → commit。

## 六、赛场纪律（4 小时蓝桥杯版）

1. **开局 5 分钟扫全卷**：标出「必做 / 可做 / 放弃」三档，先做填空。
2. **填空题**：只提交答案、**没有部分分**。算完必须验证（暴力程序 + 手算/小数据），
   不确定的答案先记下来，别在填空中途耗超过 15 分钟。
3. **编程题先写暴力**：能拿 30–60% 的测试点就先交一版，再优化；不要一上来就写正解。
4. **单题 40 分钟卡住就换**：换之前把思路和已写代码留着。
5. **提交前 15 秒自查**：多测清空 / 数组开够 / `long long` / 取模减法 / 无向边表 ×2 / 二分边界。
6. **最后 30 分钟只做两件事**：检查已提交题的边界数据 + 补一道有把握的题，不碰新难题。

## 七、收口与不达标处理

**B4（国赛前最后一周）清单**

```text
1. 两种模拟各 1 场：4 小时省赛真题、4 小时国赛真题（真题来源待补充）
2. 蓝桥杯必背 20 个模板，随机抽 8 个，每个 ≤10 分钟默写
3. 把 A1–B3 里看题解才做出来的题，关掉题解重写一遍
4. 填 04 的赛前自检 4 项，写 3 行复盘（哪类题反复卡 / 下一阶段主攻什么）
```

**不达标处理**

| 情况 | 处理 |
|---|---|
| 省赛没进省一（无国赛资格） | 国二目标顺延到下一届；**不追加长线计划**，按 A 段循环补短板，等下一届赛程出来再排 |
| 省一但国赛没到国二 | 记录失分题型（填空错几个 / 编程差几题），下一届只补这三类，不再重刷基础 |
| 中途状态差（焦虑/解离） | 只做「填空 3 道 + 模板默写 1 个」，其余全停；**计划允许缩到 3 h/周，不算失败** |
