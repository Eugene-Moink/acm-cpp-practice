### 模拟赛 SOP（2026 省 B · 洛谷 P16232–P16239）

**这一场就是 P0，也是 A6、P4 的同一套打法**，以后每套真题都按这个流程走，只换题号。

| 项 | 设定 |
|---|---|
| 卷子 | 2026 第十七届 · C/C++ 大学 B 组省赛，8 题 = 3 填空（P16232/P16233/P16234）+ 5 编程（P16235–P16239） |
| 时长 | **4 小时整**，中间不休息；建议放周末上午 9:00–13:00（和正赛时段一致） |
| 环境 | 只用一台机、一个编辑器，**不许开 AI、不许看题解/讨论区/榜单**；模板文件也不开（赛时能想起来才算会） |
| 交卷 | 填空题只交最终答案（数字/字符串），编程题按原题提交到洛谷，以洛谷测试点结果为准 |
| 计分 | 填空 **5 分/题**、编程 **15 分/题**，满分 **90**（分值依据见 `01` §5.3.1，是估算口径） |
| 记录 | 考完立刻在 `04` §三 填一行：填空对几道 / 编程过几题 / 总分 / 哪题卡了多久 |

**考场脚本（贴在桌上）**

1. 0:00–0:05 扫全卷，标「必做 / 可做 / 放弃」三档；**先做填空**。
2. 填空每道最多 15 分钟：写暴力程序算一遍 → 手算/小数据核一遍 → 两个一致才填。
3. 编程题先交暴力版拿测试点，再优化；**单题 40 分钟没进展就换**，把思路留在注释里。
4. 3:30 之后不再开新题，只检查已提交题的边界 + 补一道有把握的。
5. 考完 24 小时内：把没做出来的题关掉题解重写一遍，错因按 `读题/边界/数值/结构` 记一行。

### 自建比赛版（洛谷团队赛，推荐用它来跑编程题部分）

洛谷团队自带「自定义比赛」（团队 → 比赛 → 自建，赛制选 **OI**），题目可以直接选洛谷公开题，
P16235–P16239 都在主题库里，组一次以后每套真题都能复用同样的流程。来源：[洛谷帮助中心 · 团队](https://help.luogu.com.cn/manual/luogu/team/)。

**只能放编程题，填空必须单独手做**：

- 洛谷的「填空」题也是交代码判 AC，不是交答案 —— 放进比赛就变成「写个程序把那三个数算出来」，
  和蓝桥杯「只交最终答案、零部分分、格式错就 0 分」完全不是一回事。填空题就按 §考场脚本第 2 条手做、手记。
- 计分换算：洛谷 OI 赛制每题满分 100，**编程得分 = Σ(每题得分 ÷ 100 × 15)**（满分 75）；
  填空 = 对几道 × 5（满分 15）；合计满分 90，直接填 `04` §三。

**三个坑**

| 坑 | 怎么办 |
|---|---|
| 公开题目页有标签 / 难度色 / 题解，一点就剧透 | 高级团队可以把主题库题目「复制到团队」并改题面（官方文档明确写了这个用途）；免费版就只能靠自律——比赛期间不开题解页、不点标签 |
| 赛制选了 ACM 就变成「错一次罚时」，和蓝桥杯不一样 | **必须选 OI 赛制**（按测试点给部分分，和蓝桥杯一致） |
| 内部赛只有你一个人，排名没意义 | 只看分数，别看排名；比赛数据留着和上一次比 |

> 这一场打完，`01` §5.3.1 那个「45–55 分」就有真数了，也才知道省一差了哪 10–20 分。

## 二、每周固定动作（不计入 8 道题量）

- **填空专项 3 道/周**：蓝桥杯历年真题的填空题（2026 省 B 填空 3 道：洛谷 P16232 / P16233 / P16234）。
  做法固定：**先写一个暴力程序把答案算出来 → 再手算核对 → 两个结果一致才记答案**（填空题没有部分分）。
- **1 场训练赛**：**洛谷月赛（Div.2 优先）** / CF Div3-Div2 VP / ABC，三选一，只当手感训练。
  **洛谷比赛的定位是「训练赛」，不是「摸底」**：它是纯编程题、交完立刻知道对错、还有实时排名，
  和蓝桥杯「3 填空 + 5 编程、填空零反馈、一场定生死」不是一回事。摸底只能靠真题整卷（见 §模拟赛 SOP）。
  - 洛谷比赛**可以替代**CF/ABC 占掉「每周 1 场训练赛」那个位置，**不能替代** P0 / P4 / W10 的整卷模拟。
  - 洛谷 ELO 会动，但**本月不看它**（目标不是涨分）；掉分不影响任何排期。
  - 时间和课冲突就等赛后开 VP（虚拟参赛），一样计时 4 小时，别对着题解打。
- **错题重写**：本周 WA/TLE 的题，关掉题解独立重写一遍（不是重看）。
- **记第一次 WA 的原因**：每题只记一行 `读题 / 边界 / 数值 / 结构` 四选一（见 `04` §四）。
  一次 AC 率已经 67%，再压下去靠的不是多刷题，是**知道自己反复踩哪一类**——10 月的数据支持这个判断。
- **模板默写 2 个/周**：蓝桥杯必背清单见 [`05_模板库审计_2026-10-18.md`](05_模板库审计_2026-10-18.md) §八。
- **周日**：填 [`04_度量表.md`](04_度量表.md) 本周行 → `git add . && git commit -m "add new note" && git push`。

> 只做 12 h 的周：砍「训练赛」和 1 道题，**填空专项与模板默写不能砍**——这两项是蓝桥杯的直接分数。

## 四、模板纪律（蓝桥杯口径）

- 蓝桥杯考的是**能不能在赛场上默出来**，不是「见过」。所以每个模板的标准是：
  **关掉所有文件，10 分钟内从空白写出来并通过编译 + 自己造的 3 组数据。**
- 必背 20 个清单见 [`05_模板库审计_2026-10-18.md`](05_模板库审计_2026-10-18.md) §八（前缀和差分、二分、离散化、并查集、
  Dijkstra、Kruskal、拓扑、LIS/LCS、01背包/完全背包、区间DP、树形DP、快速幂、gcd、组合数、KMP、哈希、树状数组、ST表、线段树）。
- 模板库现状 `00_模版/` **76 个 .cpp**，索引 `00_模版/README.md`；缺的大件（线段树、ST 表、树形 DP、Trie、Tarjan 等）
  按 `00_模版/README.md` 待补清单排，**先学模板、再拿题库题验证**。
- 写完一个模板：`g++ -std=c++17 -fsyntax-only` 过语法 → `00_模版/README.md` 加行 → commit。

## 六、赛场纪律（4 小时蓝桥杯版）

1. **开局 5 分钟扫全卷**：标出「必做 / 可做 / 放弃」三档，先做填空。
2. **填空题**：只提交答案、**没有部分分**。算完必须验证（暴力程序 + 手算/小数据），
   不确定的答案先记下来，别在填空中途耗超过 15 分钟。
3. **编程题先写暴力**：能拿 30–60% 的测试点就先交一版，再优化；不要一上来就写正解。
4. **单题 40 分钟卡住就换**：换之前把思路和已写代码留着。
5. **提交前 15 秒自查**：多测清空 / 数组开够 / `long long` / 取模减法 / 无向边表 ×2 / 二分边界。
6. **最后 30 分钟只做两件事**：检查已提交题的边界数据 + 补一道有把握的题，不碰新难题。
