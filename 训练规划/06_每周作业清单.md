# 06 · 每周作业清单（蓝桥杯赛前 10 周 × 每周 8 道 = 80 道）

> **唯一目标**：蓝桥杯贵州省 C/C++ 大学 B 组 国二。节律见 [`02_蓝桥杯赛前执行计划.md`](02_蓝桥杯赛前执行计划.md)，
> 目标与诊断见 [`01_现状与目标.md`](01_现状与目标.md)，题库索引见 [`03_题单_全板块主线.md`](03_题单_全板块主线.md)。
>
> 基准：**CF 1356**（2026-10-18 实抓）→ **上限 1656**（基准 +300）；差值 = 难度 − 1356。
> 数据来源：CF 官方 problemset rating；AtCoder 用 kenkoooo 推定难度（非官方分，跨平台换算仅供参考）。
> 洛谷只给色标、没有可换算数值 → 难度栏写「待补充」，差值栏写「—」。
>
> **范围**：A1–A6 是省赛冲刺（48 道），B1–B4 是省赛后的国赛冲刺（32 道）。
> 省赛没拿到省一（没有国赛资格）时，B 段不执行，见 02 §七。
> **完成状态**：每行最后一列 ☐ 是打勾位，做完改成 ☑（编辑本文件即可，顺手 commit）。

## 节奏建议

- A 段（W1–W6）：每周 8 道里 5 道 CF/ABC（实现/前缀二分/字符串/搜索/DP/图论）+ 3 道模板题；周末打省赛真题模拟。
- B 段（W7–W10）：每周 8 道里一半是洛谷模板题（BIT/ST/线段树/区间DP/树形DP/背包），一半是 CF 综合题。
- 每道题 40 分钟没思路：看题解 → 关掉 → 自己重写 → 写一句「这题卡在哪」。
- 填空题不在这张表里，按 02 §二 每周 3 道的固定动作单独做。
- 做完立刻打勾，周日 `git add . && git commit -m "add new note" && git push`。
