## 节奏建议

- A 段（W1–W6）：每周 8 道里 5 道 CF/ABC（实现/前缀二分/字符串/搜索/DP/图论）+ 3 道模板题；周末打省赛真题模拟。
- B 段（W7–W10）：每周 8 道里一半是洛谷模板题（BIT/ST/线段树/区间DP/树形DP/背包），一半是 CF 综合题。
- 每道题 40 分钟没思路：看题解 → 关掉 → 自己重写 → 写一句「这题卡在哪」。
- 填空题不在这张表里，按 02 §二 每周 3 道的固定动作单独做。
- 做完立刻打勾，周日 `git add . && git commit -m "add new note" && git push`。
