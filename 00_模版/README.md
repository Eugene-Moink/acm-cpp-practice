# 算法模板索引

`00_模版/` 下的模板库总目录。所有模板均已通过 `g++ -std=c++17 -fsyntax-only` 语法检查。

## 目录约定

```
00_模版/
├── 00_基础工具/          纯语法/线性技巧，无数据结构依赖
├── 01_数据结构/
├── 02_图论/
├── 03_数学/
├── 04_字符串/
├── 05_动态规划/          （待补）
├── 06_计算几何/          （待补）
└── 99_杂项/              （待补）
```

- 一级目录 = 算法大类（`编号_名称`），二级目录 = 细分方向，三级 = 具体算法文件。
- **一个文件一个算法**，文件名格式 `主题_细分.cpp`，中文命名便于搜索。
- 所有模板都是**片段式**：文件里**不写** `#include`、`using namespace std;`、`using ll = long long;`，也**不写 `main`**，
  只保留函数 / `struct` / `solve()` 片段，用时直接粘贴进自己的代码框架。调用示例一律写成文件末尾的注释块。
- 文件顶部注释块统一写：用途 / 输入 / 输出 / 复杂度 / 易错提醒。新增模板请照此格式。
- 代码体内**不写解释性注释**，只保留三类：文件顶部说明块、多算法文件的分节标记、以及「无向图请加上下面这行」
  「`init_comb()` 必须在处理查询前调用一次」这类影响使用的操作提示。

### 关于「多组数据」注释

约 20 个模板里带有 `多组数据：取消 main 中 // cin >> T; 的注释` 一行。这里的 `main` 指**你自己代码框架里的 `main`**
（模板文件本身按约定不带 `main`）：把框架里 `cin >> T;` 那行取消注释即可支持多组数据。

## 已知风格差异（暂未统一）

- 缩进：大部分文件 4 空格，`快速幂.cpp`、`欧拉筛.cpp`、`质因数分解_试除法.cpp` 为 2 空格。
- 全局常量：`INF` 多为 `const ll INF = 1e18`，`多源bfs.cpp` 为 `const int INF = 1e9`；`MOD` 有 `int` 也有 `ll` 版本。
- 素数表：`欧拉筛.cpp` 用 `vector<bool> is_prime` + `prime`，`欧拉函数.cpp` 用 `bool is_prime[]` + `primes`，命名不统一。
- `Kruskal.cpp` 内联了一份 `DSU`（与 `01_数据结构/并查集/并查集.cpp` 重复），为保证单文件自包含而保留。
