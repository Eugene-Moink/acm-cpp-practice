# 算法模板索引

`00_模版/` 下的模板库总目录。当前 **76 个模板**（上一轮 64 个；2026-10-18 审计新增 12 个）。
查找算法用 Ctrl+F 搜函数名或算法名即可。

## 命名规范

文件名统一为：`算法名[_限定词].cpp`

| 规则 | 说明 | 正例 | 反例 |
| --- | --- | --- | --- |
| 分隔符 | 主名与限定词之间用半角下划线 `_`，且只用一个 | `Dijkstra_堆优化.cpp`、`Z函数_扩展KMP.cpp` | ~~`Dijkstra堆优化.cpp`~~ |
| 缩写大写 | 英文专有名词 / 缩写全大写 | `多源BFS.cpp`、`SG函数.cpp`、`LCA_倍增法.cpp`、`KMP.cpp` | ~~`多源bfs.cpp`~~ |
| 不重复目录名 | 文件名不重复父目录已经表达的语义 | `03_数学/博弈论/SG函数.cpp` | ~~`博弈论/博弈论_SG函数.cpp`~~ |
| 目录同名也带限定词 | 同一目录下可能有多份同类模板时，文件名要能区分 | `并查集/并查集_路径压缩.cpp`（另有 `带权并查集` 待补） | ~~`并查集/并查集.cpp`~~ |
| 术语用通行叫法 | 便于回忆 | `最大子段和_Kadane算法.cpp` | ~~`连续子列和_Kadane算法.cpp`~~ |
| 其他 | 不用空格、不用全角括号、不写 `_v2` / `_remake` 之类的版本后缀 | | |

## 文件约定

- 一级目录 = 算法大类（`编号_名称`），二级目录 = 细分方向，三级 = 具体算法文件。
- **一个文件一个算法**，多算法合订必须在文件内用分节标记分开（参照 `00_基础工具/进制转换.cpp`）。
- 所有模板都是**片段式**：文件里**不写** `#include`、`using namespace std;`、`using ll = long long;`，也**不写 `main`**，
  只保留函数 / `struct` / 全局常量 / `solve()` 片段，用时直接粘贴进自己的代码框架。
- 文件顶部注释块统一写五个字段，顺序固定：**【用途】【输入】【输出】【复杂度】【易错提醒】**。
- 代码体内**不写解释性注释**，只保留三类：文件顶部说明块、多算法文件的分节标记、以及「无向图请加上下面这行」
  「`init_comb()` 必须在处理查询前调用一次」这类影响使用的操作提示。
- 调用示例统一放在文件末尾的 `/* ==================== 调用示例（贴进自己的 main） ==================== */` 注释块里。
- 缩进 4 空格、Allman 大括号、不使用制表符。
- **自包含**：文件内用到的 `struct` / 常量都在本文件里定义，不引用其它模板文件。

## 常量约定

| 常量 | 写法 | 用途 |
| --- | --- | --- |
| `INF` | `const ll INF = 1e18;` | 距离、最短路；纯网格的 int 距离可用 `const int INF = 1e9;` |
| `NEG_INF` | `const ll NEG_INF = -1e18;` | 负无穷哨兵（背包「恰好装满」等） |
| `MOD` | `const int MOD = 998244353;` | 取模（也有 `const ll MOD` 版本） |
| `MAXN` | `const int MAXN = ...;` | 定长数组规模 |

每个模板文件**自带**自己需要的常量。一次只贴一个模板；若把多个模板贴进同一份代码，注意删掉重复的常量定义。
这是有意为之的取舍：优先保证「单文件复制即可用」，而不是「全部模板能拼成一个 TU」。

## 质量校验

README 里声明过的校验方式已修正为实际操作（**片段式文件不能单独 `-fsyntax-only`**）：

```bash
# 1) 语法校验：把标准前缀拼在模板前面再编译
{ echo '#include <bits/stdc++.h>'; echo 'using namespace std;'; echo 'using ll = long long;'; cat 模板.cpp; } > /tmp/chk.cpp
g++ -std=c++17 -fsyntax-only /tmp/chk.cpp

# 2) 正确性校验：把模板包进 namespace 后与暴力对拍
g++ -std=c++17 -O1 -o selftest selftest.cpp && ./selftest
```

## 维护规则

1. **一个文件一个算法**，多算法合订要用文件内的分节标记分开。
2. 每写完一个模板，立刻在本 README 对应表格加一行；「待补清单」同步更新。
3. 每月 1 号做**闭卷默写测试**：随机抽 5 个模板，限时 10 分钟/个，错的重写。
4. 新增模板必须过「质量校验」一节的两步：拼接前缀 `-fsyntax-only` + 暴力对拍。
5. 比赛里现学的新套路，赛后 24 小时内补成模板 —— 这是模板库增长最快的方式。
